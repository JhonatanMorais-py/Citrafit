# Citra Fit

Site estático do Citra Fit, pronto para GitHub e hospedagem.

## Estrutura

- `index.html`: página inicial
- `styles.css` e `app.js`: estilos e comportamentos da página inicial
- `assets/`: imagens e fontes da página inicial
- `demo/`: demonstração completa do Citra Fit

## Publicação

Envie todo o conteúdo desta pasta, preservando a estrutura dos arquivos.

- Em hospedagens estáticas, use a raiz do projeto como diretório de publicação.
- Não é necessário executar build nem instalar dependências.
- O arquivo de entrada é `index.html`.
